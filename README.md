## Project Overview
An Android application built using Kotlin, XML layout files, and Fragments that interacts with the `nit3213apinew` server to handle student login authentication and retrieve a live world languages dataset dynamically.

## Architecture & Technical Requirements
- **Architecture:** MVVM (Model-View-ViewModel) with Fragments and View Binding.
- **Dependency Injection:** Dagger Hilt for network module management.
- **Networking Layer:** Retrofit 2 with custom Gson deserialization.
- **UI Toolkit:** Classic Android XML Layout templates with a RecyclerView list.

## How to Build and Run the Application
1. Clone or download this repository folder link.
2. Open Android Studio (Ladybug or newer recommended).
3. Select **File > Open** and choose the `s8129912Assignment2` project root directory.
4. Allow Gradle to sync completely with the project dependencies.
5. Select a virtual emulator device configuration (e.g., Medium Phone API 37).
6. Press the green **Run** button to compile and execute the application.
